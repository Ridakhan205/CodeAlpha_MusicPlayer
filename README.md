**🎵  Music Player**
An interactive, retro-inspired music player with cassette tape aesthetic, real-time visualizer, and full playlist management.

**✨ Features**
🎮 Playback: Play, pause, next, prev, shuffle, repeat with keyboard shortcuts

📊 Visualizer: Real-time frequency bars that animate with audio

🎚️ Cassette UI: Spinning reels, glow effects, retro design

📂 Playlist: Add/remove tracks, like favorites, download audio files

🎯 Drag & Drop: Upload audio files by dragging onto the panel

🎵 Demo Tracks: 5 built-in synth-generated tracks (Synthwave, Lo-fi, Ambient, Electro, Chillhop)

⌨️ Keyboard: Space (play/pause), Arrow Left/Right (prev/next)

**🛠️ Technologies**
HTML5 - Structure

CSS3 - Animations, responsive design, custom properties

JavaScript (ES6+) - Web Audio API, Canvas API, DOM manipulation
